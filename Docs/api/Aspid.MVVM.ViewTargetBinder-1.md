## Constructors

### ViewTargetBinder\(TView, BindMode\) {#Aspid_MVVM_ViewTargetBinder_1__ctor__0_Aspid_MVVM_BindMode_}

Creates a forward-only view binder.

```csharp
protected ViewTargetBinder(TView target, BindMode mode = BindMode.OneWay)
```

#### Parameters

`target` TView

The view to bind.

`mode` [BindMode](Aspid.MVVM.BindMode.md)

The binding mode. Must be [`BindMode.OneWay`](Aspid.MVVM.BindMode.md) or [`BindMode.OneTime`](Aspid.MVVM.BindMode.md).

#### Exceptions

 [ArgumentOutOfRangeException](https://learn.microsoft.com/dotnet/api/system.argumentoutofrangeexception)

<code class="paramref">mode</code> is [`BindMode.None`](Aspid.MVVM.BindMode.md) or undefined.

 [ArgumentNullException](https://learn.microsoft.com/dotnet/api/system.argumentnullexception)

<code class="paramref">target</code> is <a href="https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null">null</a>.

 [InvalidOperationException](https://learn.microsoft.com/dotnet/api/system.invalidoperationexception)

<code class="paramref">mode</code> includes reverse binding.

### SetValue\(IViewModel?\) {#Aspid_MVVM_ViewTargetBinder_1_SetValue_Aspid_MVVM_IViewModel_}

Deinitializes the live view before applying the new ViewModel.

```csharp
public void SetValue(IViewModel? viewModel)
```

#### Parameters

`viewModel` [IViewModel](Aspid.MVVM.IViewModel.md)?

The new ViewModel. A <a href="https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null">null</a> or destroyed ViewModel leaves the view deinitialized.

#### Remarks

A newer value or detachment during deinitialization cancels this update.
